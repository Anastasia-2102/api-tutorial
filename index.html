How to Call the Dog CEO API

Learn how to send API requests and read JSON responses in the browser.

Step 1 - The URL is the request

What I did: I sent a request to the Dog CEO API. What I saw: the API returned a dog image address and a success status.

Status: 200

  "status": "success"

Read the Dog CEO API documentation.

Day 1 - Reflection

Something challenging

Understanding the difference between a request and a response was challenging at first. I also had to learn how JSON organizes data into objects and properties.

A trap to watch for

A common JSON mistake is forgetting the double quotes around a property name. Without the quotes, the response may look almost right, but it is not valid JSON.

One request, different answers

What I learned: I can use the limit query parameter to control how many cat records the API returns. Changing the value from 1 to 10 changed the number of records in the response.

When the API asks for a key

What I learned: some APIs require an API key before they will return data. The key goes in the X-Api-Key header instead of being added to the URL.

Status: 400 - missing key

Status: 200 - with API key

Status codes tell the story

I learned that a status code tells me what happened with my API request. A 200 status code means the request was successful, while a 400 status code means there was a problem with the request.

Status: 200

API keys go in a header

I learned that some APIs require an API key before they will return data. I sent the key in the X-Api-Key header and saw the response change from a 400 status code to a 200 status code.

Status: 400 → 200

How the describe Function Works

function describe(pet) {
  console.log(pet.name + " comes from " + pet.origin + ".");
}

The parameter is pet in the function definition. When I call the function, pets[0] is the argument passed to the parameter. The function uses the cat's name and origin to create the sentence.

Why the Button Needs an Anonymous Function

I learned that adding parentheses to the function call makes the function run immediately instead of waiting for the button click. An anonymous function lets the browser wait until the button is pressed, and then it calls showPet with the cat I chose.

Parameter and Argument

I learned the difference between a parameter and an argument. In showPet(pet), pet is the parameter, and when I call showPet(pets[0]), pets[0] is the argument that is passed to the function.
