How to Call the Dog CEO API

Step 1 — The URL is the request

What I did: I sent a request to the Dog CEO API. What I saw: the API returned a dog image address and a success status.

{
  "message": "https://images.dog.ceo/breeds/maltese/n02085936_4262.jpg",
  "status": "success"
}

Day 1 — Reflection

Something challenging

Understanding the difference between a request and a response was challenging at first. I also had to learn how JSON organizes data into objects and properties.

A trap to watch for

A common JSON mistake is forgetting the double quotes around a property name. Without the quotes, the response may look almost right, but it is not valid JSON.
